# 武侠世界：三篇剧情与任务设计

版本：0.3 · 日期：2026-09-23 · 状态：探索式剧情设计稿，尚未制作或完成原著逐项考据

配套文档：[架构与系统](./ARCHITECTURE.md) · [开发计划](./DEVELOPMENT_PLAN.md)

> **全篇剧透。** 本文给出三篇连续故事的主线、支线、感情线和终局。它是原创游戏剧情设计，不是任何原著的情节、官方人物强弱排序或已获授权的发行文案。角色具体版本、章节和年龄依据仍需在人物档案中逐项核对；公开发行所需授权另行确认。

## 0. 三篇总览

1. **第一篇《众路归潮》**，六章：一封假求援书把不同作品人物引到江南。玩家查出许观澜以改信和人为危机控制驿路，救下旧渡的人，并决定百路簿的阶段性保管方式。
2. **第二篇《烽火未起》**，六章：许观澜的底账牵出更大的囤粮与私兵网络。各地对第一篇的处置产生分歧，盟友因救人顺序和感情承诺互相伤害。玩家虽阻止一场误战，却没能阻止幕后者准备全面封路。
3. **第三篇《华山前夜》**，六章：各路人物在关道与渡口迎战私兵，保住粮路和百姓撤离。大战之后于华山论剑，从参会者中决出本作的五位“新五绝”；主角最终可留在江湖，或在一次不可重复的机会中返回现代。

三篇属于**同一个连续存档与同一世界**，共 18 个短章节关口；三篇终章按第一篇第六章 → 第二篇第一章 → 第三篇第一章接续，但每篇已开放地域可自由往返，同一调查段内的地区事件可按玩家到访顺序发生。章节号只标记世界局势与必要证据的推进，不是逐站点游览清单。篇章切换结算已发生的事实、人物行程和明确提示过的支线时限，开放新地域，不重置等级、关系或物品。1.0 暂估必做主线 **16–20 小时**，主动探索与支线合计 **40–55 小时**；第二阶段玩法 Demo 仍只交付第一篇第一章。时长与任务量在 M3、M5 按试玩和资产产能重估。

三篇的情绪曲线为“相识与信任 → 分歧与失去 → 并肩承担与告别”。冲突来自人物掌握的信息、实际资源和各自所爱之人，不能靠误听一句话就让聪明人物长期误会；重要伤亡与背离必须有前因、可见抉择和后果。恋爱是可选择的主要叙事线，既有友情路线，也允许多位知情且自愿的成年角色与主角建立恋人关系；具体规则见第 8 节。

现代普通人因一次无法重现的异象来到群侠同世的江湖。江南一封求援书让令狐冲、黄蓉和萧峰相遇，也让主角发现：有人借驿路和赈灾之名，截改各地消息，制造人与门派之间的误判，继而要求所有人接受他掌控的“通路盟约”。主角要查明自己为何来到这里，找出被篡改的消息，把选择权还给卷入其中的人，并决定自己以后以何种方式留在江湖。

第一篇不是穿梭原著年代，也不是集合所有小说人物的总决战。现代记忆只提供观察角度；主角对原著的零散记忆可能失准，不能当作人物未来的可靠信息，也不能靠现代知识制造无敌武器。故事里出现的是同一个架空世界、同一时段的人物；跨作品人物因真实的道路、救援和信任问题相遇、合作或争执。

第一篇必做主线目标为 5–6 小时，主动探索与支线约 12–18 小时。第二阶段玩法 Demo 使用第一篇第一章“江南会客”，独立体验约 60 分钟；第一阶段 M0 仍只是场景与 UI 视觉展示，不要求实现这段剧情。全部任务 ID 是未来内容配置的稳定草案，进入制作后如需改名须提供迁移映射。

### 1.1 主题与人物动机

核心问题是：当一张记录道路与行踪的账簿足以救人，也足以伤人时，谁有权决定它如何使用？令狐冲警惕被规矩捆住的江湖，黄蓉愿意算清证据和代价，萧峰先顾受困者的生死。三人的方法会冲突，彼此却不是玩家必须击败的对手。主角的长处是串联证词、承认自己不知道的事，再把选择交还当事人。

反派许观澜是原创人物，原为民间“同路会”驿站账房，掌握路线、船期和转信人名单。他曾因信使失联导致救援失败，遂认定分散的江湖只有被一套通行规矩统辖才能免于误事。他起初确实救过人，此后却开始扣信、伪造求援、安排有限度的危机，再展示自己才有能力疏通道路。目标是让各门派与民间驿站交出人手和行程，承认其独占的盟约。手段伤害平民，也使他失去道德退路；最终可被阻止和审问，不以突然觉悟抵消责任。

### 1.2 世界规则与人物基线

- “同路会”是本作原创的民间驿路组织，既非任何原著门派，也不统领原著人物。许观澜只控制一部分渡口、驿站和雇员。
- “百路簿”记录路线、船期、接信人和求援优先级。它没有预言能力，所谓“先知”来自监听、统计与人为改信。手抄副页能在不同地点出现；原本只有一份，归属变化有任务记录。
- “归潮石”是江南旧渡留下的异石。主角在现代接触到与之断面相合的残片，同时旧渡遭雷雨冲开，于一次共鸣中来到此地。第五章找到吻合的断面、主角现代照片和旧渡记录，足以解释本次穿越；当时的共鸣已消失，第一篇不能回家。第二、三篇通过可查的石纹与观测记录逐步发现最后一次单人回返条件，终局由主角选择是否使用；异象不成为可反复使用的跨界系统或战斗能力。
- 金庸人物在此世界保有各自小说主要剧情阶段的年龄、身份、关系和已知经历。下表只给剧情使用的阶段方向，**不能替代正式人物档案中的参考版本、章节、年龄依据和身份核验**。某阶段若与原著不符，应修正事件时间与对话，不通过改龄或改换核心身份解决。

| 人物 | 本作拟用的主要剧情阶段方向 | 第一篇中的独立目标与边界 |
|---|---|---|
| 令狐冲、任盈盈 | 已相识且任盈盈已成年的主要剧情阶段；具体身份随版本核定 | 追查被冒用的江湖传信，不被写成只听主角指挥 |
| 黄蓉、郭靖 | 黄蓉已成年、二人仍结伴游历的主要剧情阶段；称谓与已有经历待核 | 查赈粮和失踪信使；初始关系完整，后续若改变须有两人的独立事件与自主选择 |
| 萧峰、阿朱 | 阿朱已成年、萧峰已知自身身世且二人同行的主要剧情阶段；具体前后事件待核 | 救人并找出借其名义发信者，不预支锚点之后的原著经历 |
| 段誉、虚竹 | 各自已形成代表性武学与身份的主要剧情阶段；具体称谓待核 | 分别处理救援路线与伤者安置，不被赋予全知解谜能力 |

第一篇首章仍只需上表中的三位经典人物直接互动；全篇可通过探索另遇少林空闻、武当张三丰、峨眉周芷若与丐帮洪七公。第二篇候选加入张无忌、赵敏、杨过、小龙女；第三篇让这些相识者依据前事参与战争或各自收束。新增人物均是**待核候选**，来源、版本、章节、年龄与身份核验项见[人物考据待办](./canon/CANDIDATES.md)；核验前不写死职务、精确岁数、原著经历或正式对白。可同行候选仍以原有 7 位为基础，新增人物先以地区事件和临时助阵进入，不直接膨胀常驻队伍或 M3 资产范围。同场队伍始终为主角加最多 3 人，任盈盈与阿朱第一篇不作为常驻可操作伙伴。

## 2. 主线全貌

主线只保留“查到改信事实 → 取得可公开罪证 → 制止封路 → 决定账簿归属”的必要关口。玩家进入地点并满足公开可理解的线索条件时，事件才出现；可以先探少林山道、武当驿或粮仓，再决定追哪条地区故事。普通战败可重试或回安全点；任何可选调查、关系值、支线失败都不能造成主线死锁。逻辑时辰影响在场对白、巡逻和支线提示，不让无提示等待造成主线人物永久错过。下表是**必要关口及保底线索**，各地人物经历详见可选支线，不要求逐项看完才能进入下一篇。

### 2.0 探索触发与局部汇合

玩家从大地图选已发现的道路，进入地区后检查“所在地点 + 已知线索/世界事实 + 人物当前是否可用 + 事件是否已结算”。交互点、传闻与见闻札记提示尚未满足的**方向**，不把条件藏在无提示时辰或隐形好感阈值里。未接取的地区事件留在地图上；只有玩家已知晓且被明确告知时限的救援事件，才可随局势推进进入失败收束。探索、训练、普通旅行不自动推进篇章或让远方事件全数过期。

| 事件组 | 可先到哪里 | 主线汇合条件 | 缺席时的保底 |
|---|---|---|---|
| 第一篇查信 `quest.main.02` / `.03` | 第一章后粮仓与山门路同时开放；乔红绡提供山门旧路，粮仓记录提供另一条路 | 两处各取得一份核心证据后，北岭驿出现许的盟约事件 | 门派、药庐和证人支线均可跳过；底账在抄写房固定可得 |
| 第二篇查粮 `quest.main.08` / `.09` / `.10` | 第七章后，粮仓、被胁迫者所在安全点与旧观测地分别出现线索 | 粮价操纵及沈槐证词或替代旁证就位后，白河危机开放；石纹记录在第十二章前须从主线保底点读取 | 沈槐不在场由原索引和仓库记录替代；回返依据不靠雨簿支线 |
| 第三篇备战 `quest.main.14` / `.15` | 第十三章后，江南撤离与峡口议事可按行程先后触发 | 两处结算后开放第十六章多战区；未去江南时，议事先用可信信使报告，回访补全人物场景 | 任何可选门派未结盟，普通渡工与各地自救队仍给最低资源 |

同组事件只改变可见顺序，不生成每种排列的一整条新主线。每组在汇合处写入少数明确事实，例如证据是否完整、谁受伤、哪条路先修；终局按这些事实和关系承诺组合尾声片段。18 个章节 ID 不改，章节结算顺序允许上述并行组互换；跨篇终章顺序仍固定，避免战后人物跑回尚未发生的战场。

### 2.1 第一章：江南会客（完整 Demo 流程）

**开端，0–5 分钟。** 主角在暴雨后的芦湾醒来，衣袋里有一张参观现代展馆时留下的残片纸质照片和拓印。陆青禾指出河道没有主角记忆中的建筑，带其入客栈求助。主角先学会调查交互，并在见闻札记中分开记录“亲见的旧渡石痕”和“我猜它与现代残片有关”。开场不让主角讲述原著人物的未来。

**会面，5–15 分钟。** 乔红绡同时收到写给令狐冲、黄蓉、萧峰的求援书，称芦湾旧渡有一队赈粮船失踪。她先笑骂驿站办事不牢，再把三人各自收到的信摆在桌上，要求先查船夫下落。信中还暗示三人中的某位泄露了救援行程；许观澜本想让他们互疑、延误救人，再借失败推销统一调度。令狐冲认为语气像冒名旧友，黄蓉发现纸张来自本地驿站却盖了远处的转信章，萧峰关心失踪船夫是否还活着。三人相互质疑信息来源，讨论谁应先去救人；玩家通过听取三人的观察形成第一份时间线。关键线索“水位与船牌不符”由乔红绡和渡口告示保底给出，隐藏调查只改变后来识破陷阱的先手条件。

**成长，15–25 分钟。** 玩家从令狐冲的破绽观察、黄蓉的机变与站位、萧峰的护人节奏中选一个教学切入点，获得主角可用的基础招式或战术训练。角色不是直接转授独门绝学。可与其中一人短切磋，或做无胜负的训练；三种基础玩法都能应对后续战斗。可选支线 `quest.side.01.missing_ferryman` 在此接取，调查失踪渡工，完成可降低首领战环境压力。

**同行与旅行，25–35 分钟。** 玩家选一位主要同行者，乘渡船前往芦湾。其余人按各自理由分头查验，并不会消失或从属于主角。选令狐冲可在战前发现押运队的伪装，选黄蓉可先拆机关，选萧峰可先救出被扣的渡工；未选路径的信息在战后由对应人物补齐，避免锁死主线。

**冲突，35–50 分钟。** 唐守亭想取回假信并令众人误以为另一位侠客泄密。玩家在旧渡发现被锁的船和可见的水门机关。战斗第一阶段需要击破锁链或压制机关，第二阶段出现被囚渡工；继续输出首领会拖慢救援。另一位来自不同作品的经典人物到场、与主要同行者协作参战：令狐冲先行时由萧峰加入，黄蓉先行时由令狐冲加入，萧峰先行时由黄蓉加入。援手拥有实际可选行动，敌人的机关机制因此改变；没有经典人物之间的强制胜负对决。

**选择与收束，50–60 分钟。** 唐守亭被制伏后供出转信副页。玩家决定先将其公开给客栈众人共同作证，或先交受害渡工密封保管以保护姓名。前者让后续证人更易聚集但许观澜提前收紧路线，后者保住受害者隐私但要在第二章多走一步核验。无论选择，都得到签押线索并能继续主线。三侠根据玩家的救援、战斗和处理方式表达不同意见；陆青禾在客栈贴出已获救者名单。玩法 Demo 在这场救援完成、下一章路线开启的节点结束，形成自己的事件结局。

本章第一次战斗可由训练切磋或押运队小规模冲突承担；机制战和唐守亭结局战可合并为同一场两阶段战斗。按试玩节奏将总战斗控制为 3–4 场，允许一场可选，不把可选支线变成通关前置。

### 2.2 第二章：两封真信

玩家可循副页先到江南粮仓，也可先走乔红绡指的山门旧路，返程再核对粮仓。郭靖和黄蓉在护送粮车时发现收粮名单多出一个不存在的村庄；段誉带来另一封有相同真章的求援书，内容却指向反方向。两封信证明正文曾在转信环节被替换；主线只需核对收粮记录并取得驿站位置。救出信使家属、追查不存在的村庄和进一步还原换信手法可由地区故事完成。若第一章选择密封副页，受害者在这里主动给出见证；若公开，乔红绡提前联络证人但驿站守卫更多。结果汇合在“找到换信地点”。

### 2.3 第三章：山门借道

山门路出现两批错过救援时机的伤者。虚竹留在药庐照看伤者，段誉负责寻找可通行的小路；令狐冲和任盈盈各自追查一封被冒名寄出的信。玩家要选择先护送伤者还是先追截送信人：前者更多人得到及时医治，后者可保留额外的送信口供。沈槐是否获救由该选择、支线和战斗表现决定，但其藏在抄写房夹层的底账总能被发现。许观澜为确保自己能精确控制换信和船期，仍保留签押底账；沈槐偷偷誊写的索引让其中缩写可被辨认。底账表明许曾故意延迟小规模救援，随后以自己开通的路线赢得“必须统一调度”的声望。章末收到北岭驿将举行路盟宣告的消息。

### 2.4 第四章：北路断信

许观澜第一次正式登场。他公开承认调度有失，却声称分散传信才是灾祸根源，提议各方交出信使姓名、客栈落脚点和旅程计划。郭靖愿意先协助疏散而拒绝交出全部名单，黄蓉查证路盟条款，萧峰与阿朱追一名被栽赃的信使。玩家在封闭关道上夺回真求援书，证明许观澜同时给对立两方发了相反命令，导致救援迟到。战后许观澜逃往归潮渡，准备在更大的险情中让众人“自愿”交权。主角也发现许的总账引用了归潮旧渡石室，自己的来处与此地终于出现可查的连接。

### 2.5 第五章：归潮旧石

石室壁上有与主角现代照片相合的残片断面。旧渡记录描述雷雨中石面曾短暂映出陌生城景，此后多年未再发生；结合主角跨界当日的雷雨、拓印和现存断面，确认这是一场偶发的双界共鸣，而非许观澜制造。此时没有重启通道的办法，第二篇才取得旧观测记录，第三篇才知一次回返的条件。主角可以承认自己不能保证回家，也可以暂时不告诉同伴全部记忆；两种表达影响人物对其坦诚的评价，不影响主线证据。

同路会总账房有完整百路簿，既记许观澜改信的签押，也记无辜者的隐私。石室进水时先救被困抄写员、先搬账簿或分队两顾，改变证人存活、私密页保存和终章可用的对质材料；分队若缺少此前取得的渡船或可信援手，会有人受伤。无论怎样，主角都带走证明许改信并制造危机的公事页；额外证据可减少终章对峙难度、改变后日谈，不能变成唯一通关钥匙。

### 2.6 第六章：众路公证

许观澜在归潮渡聚人会盟，提前封闭几条旧路，让洪水前的运粮和撤离必须经过他的船队。玩家先完成两个有明确战术差异的救援：护送百姓过桥、夺回被扣的备用渡船。此前救出的渡工、伤者、信使与伙伴各有可见帮助；缺席时由普通渡工和主线保底路径补位，只增加困难，不使主线失败。

会盟场上，许观澜以过去救人的功绩为自己辩护。令狐冲拒绝个人控制所有去路，黄蓉逐笔指出改信时间，萧峰带来被耽误的生者证词；玩家选择展示哪些可公开材料，并保护私密名单不被误作罪证公开。最后一战是与许观澜的押运队争夺渡口控制：要守住疏散队列并切断封路机关，不以击倒所有人作为唯一胜利条件。许被制伏后交由受害者与各地见证人共同审问，结尾选择百路簿的阶段性处理方式。其账中一笔来自北方私兵仓的长期付款，成为第二篇入口。

## 3. 第一篇关键选择与阶段结局

### 3.1 分支规则

主线分支采用局部差异后汇合。第一章副页保管方式、第三章救援优先级、第五章石室救援和第六章百路簿处置都会记录不可逆事实；前三项不锁住主线证据。所有重要选择在确认前说明即时风险；后续具体人物态度由剧情呈现，不在选项上伪装唯一正确答案。

| 事实或状态 ID | 取值 | 产生与用途 |
|---|---|---|
| `fact.main.letter_custody` | `public_witness` / `sealed_victims` | 第一章；改变第二章查证流程和许观澜的戒备 |
| `fact.main.mountain_priority` | `patients` / `courier` | 第三章；影响伤者、口供及终章助阵 |
| `fact.main.stone_rescue` | `people` / `ledger` / `split` | 第五章；影响证人和私密页，不影响最低罪证 |
| `fact.main.evidence_level` | `core` / `corroborated` / `complete` | 主线保底 `core`；支线与调查提高对质力度 |
| `fact.main.crossing_known` | `private` / `shared` | 第五章；改变人物后日谈，不改变穿越事实 |
| `fact.part1.ledger_disposition` | `public_charter` / `trusted_custody` / `destroy_private` | 第一篇第六章三选一，带入第二、三篇 |

关系使用已有 `RelationshipState` 的信任、承诺和见证事件表示；不靠一个“好感高”数值替代人物原则。伙伴任务影响该人物愿否助阵与后日谈，但终章主角始终有普通渡工、已取得的公事页与基础队伍可用。主线任务不能 `Abandoned`；支线放弃或错过后显示明确结果，不悄悄消失。

### 3.2 三种篇末状态

| 篇末状态 | 第六章选择与即时结果 | 代价及第二篇回响 |
|---|---|---|
| **公议开路** `outcome.part1.public_charter` | 当众公布许观澜的公事罪证，剥除私人行踪后让各地渡工、客栈和见证人共同制定公开的救援规则 | 效率提升较慢，第二篇北岭可较易召集民间证人，顾也更早警觉 |
| **托管守路** `outcome.part1.trusted_custody` | 将原账封存，交由多方各执一钥的临时托管团核验通行争议，设期限与复审 | 紧急调度较快，第二篇须先说服托管人开库；若私密页遗失，只接收存留部分 |
| **焚私断链** `outcome.part1.destroy_private` | 公开足以定罪的公事页，销毁会暴露无辜者行程的私人名单，重新建立分散的求援联络 | 隐私更安全，第二篇追线需多访一处旧驿；若支线建立备用信使网，可缩短传信时间 |

三种处理在任何可达的第一篇第六章存档均可选；缺失证人与支线不会封锁第二篇，只改变公开可信度、营救伤亡、驿路重建速度与人物态度。三条路线都确认许观澜的操纵被终止，主角明白自己如何来到江湖，但此时还不知如何回去。许观澜可在审问中认罪或仍自辩，均不洗去责任。

终幕发生在水退后的旧渡。选择公议开路时，主角把删去私人行踪的罪证钉在新设的公示板上，陆青禾或当地渡工读出第一份公开救援规则；选择托管守路时，各方当着受害者的面各执一把库钥，并定下复审日；选择焚私断链时，主角先将公事罪证交见证人，再与名单上的当事人确认私密页销毁。三条路都以一封不再经许观澜转递的求援信收束：它被送到需要帮助的人手中，回扣第一章的假信。

篇末短场景只根据已经发生的事实变化。令狐冲若受尊重，会不署名地帮下一处驿站解围；否则仍独自上路，但会留下实证。黄蓉与郭靖暂时继续结伴，以救粮与保护证人的结果评价新规则；两人的后续关系由第二、三篇实际事件决定。萧峰与阿朱带走需要护送的人，是否再次信任主角取决于玩家是否承担过保护责任。段誉、虚竹返回各自先前的事务。陆青禾依关系线决定开辟独立信使网或守护家渡。主角把现代照片和江湖新画的渡口图放在同一页札记里，此刻归路仍未打开，却已有下一封需要亲自送达的信。

这四条线各由两个可独立结算的任务组成。完成第一步开启第二步；若伙伴因主线占用暂时不在场，任务等待至其下一处固定安全地点，不生成第二个角色实体。玩家可尊重人物拒绝同行的决定；关系线收束不以“招募成功”作为唯一好结果。

| 伙伴 / 任务 ID | 第一步：开端与选择 | 第二步：收束与后果 |

| 令狐冲 `quest.bond.linghu.01` / `quest.bond.linghu.02` | **不署名的信**：第二章查到有人冒其名约战；玩家可先公开澄清或陪他找写信者。公开快，但会让对方潜逃；追查慢，却能知道信被迫写下 | **路与规矩**：第四章令狐冲不愿按同路会的统一护送表行动。玩家可提出可退出的临时协作，或强求其守队列；尊重选择可使其在终章以自己的方式助阵，强求则仍给线索但不常驻同行 |

### 4.4 支线节奏与可达性

第一章 Demo 只有 `quest.side.01.missing_ferryman` 可完成；陆青禾关系线第一步仅埋伏笔。此后原有地域任务按地点与局势线索开放，第二、三章的两处地区可以反向游历；新增四条门派任务只在玩家进入相应地区、获知传闻后出现，错过也不阻塞任何主线。伙伴线的可用地点以人物事件占用表为准，不强迫玩家按章节表清空支线。

局势推进后，尚有合理调查价值的支线可返回地点继续；玩家已经接取并明确得知时限的救援任务才可能失败。未接取不自动视为故意漠视，也不悄然标记 `Abandoned`。所有 22 条第一篇支线各有至少一条正常完成路线，单个存档不要求同时得到互斥结果。

## 5. 内容落地与验收约定

- `quest.main.01` 至 `.06` 对应 6 个短章节关口；22 条支线分别拥有独立 `QuestDefinition`。分支状态使用 `WorldState.facts`、任务阶段与关系承诺保存，不能靠是否播放过某段动画判断剧情结果。
- 每条任务配置：开放条件、接取地点、阶段目标、关键 NPC 占用、最低保底线索、失败或放弃结果、奖励、互斥分支及回收地点。跨章节 NPC 进入同一个事件占用表；若伙伴在队，剧情使用队伍实体，离队后按已记录地点返回。
- 主线必要道具包括第一章转信副页、第三章底账与第五章公事罪证；不可卖出或丢弃。副页可公开或密封，但不复制成两份不同的“唯一物”。百路簿的私人页归属和毁弃在终章一次性结算。
- 选择后果必须在下一章节或下一次安全地点至少有一次可见反馈。关键反馈包括：可用渡船、被救者名单、人物评价、战斗助阵、路线开放、证据级别与结局后日谈。
- 第二阶段主线所有可达对白分支配音；可选支线不列入 M3 必配。对白定稿后每句分配稳定 `line_id`，文本变更同步更新音频清单。M0 可取第一章客栈会面的少量样例句做视觉与音色展示，不据此宣称剧情已实现。
- 人物资料审核与内容授权状态单独记录。写作先明确动机和剧情阶段，制作前再逐一核对原著参考版本、章节、年龄段、身份、武学及已知经历；若核验发现冲突，优先调整本作原创事件和出场顺序。

许观澜被制伏后，三种百路簿处置都留有一份用于定罪的公事页。沈槐若已获救，便亲自核对转款记录；若仍失踪，主角按其留下的索引辨出北岭军需商人顾闻策的代号：许获得的船只、纸张和守卫一直由顾提供。顾曾亲历赈粮分散导致的惨败，因而建立护路私兵。他认为许的手段过急，却认同“必须由能守路的人独占粮道”。许的败露没有终止这套主张，反让顾以“稳定粮路”为名接手其残余网络。顾不是幕后神秘血亲，也不通晓归潮石；他的优势是货仓、雇佣兵和民众对饥荒的真实恐惧。

第二篇核心冲突：救眼前的人还是保留揭穿全局的证据；公开真相又会不会让粮车断供。玩家与伙伴的意见不总一致。顾利用这些分歧拉拢部分地方守军，打算先制造一次边地误战，再以自己的私兵保护粮道。主角最后阻止误战，却没能让各地立刻相信彼此，顾撤走粮草、准备第三篇的全面封路。此篇必做主线约 **5–6 小时**；粮仓、人物、门派与感情事件通过主动探索展开。

白河危机把各派对“谁有权传信和护路”的分歧显露出来：血刀门山道的错认、恒山派救护棚的名额、崆峒派和青城派的相反文书、全真教名义的避难捷径，以及五毒教药材被误责，都能在各自地图中查证。天山派雪路与红花会北路联络站给出另两种送粮和送信选择；各派独立结算，不因玩家先走哪条路就统一听命于主角。未探索这些地区，第八至十二章仍由仓票、沈槐索引和普通信使汇合，主线没有新增门派前置。

第七章从第一篇三种处置的不同后果开始：公开账页的存档会看见北岭驿贴出受害者姓名，先要帮人撕去不该公开的行踪；托管账页的存档要说服两个互不信任的持钥人同处一室；焚毁私页的存档要靠陆青禾记下的船期重建一段线路。三条路径都能找到同一笔长期付款，却让主角明白“正确处理账簿”没有让所有人立刻安全。此时顾闻策以运粮商的身份递来援手，言辞平和，提出的护路队确实解了眼前之急。

第八章让顾的诱惑有可见重量。城门外一车药粮只能先走一边，玩家要在地图上查路况、决定谁先过桥；选近处能救下夜里发热的孩子，远处病人则需等第二队，反之亦然。没有隐藏的完美第三选项。顾的车队到来后免费补足另一边，并要求城门签独家护路契。黄蓉会问粮从何来，郭靖会记下获救者确实活下来了，萧峰反对拿人的饥饿换誓书；三人的争执有事实基础，不是剧情安排谁突然犯蠢。

第九章议事桌上，沈槐亲手放下自己改过的货票，承认那行字使救援被改道。若她第一篇失踪，玩家在第七章救回她后已见到被扣的家人；若早已获救，她此前的沉默也有可查的恐惧原因。玩家可在她同意下公开证词，或先去救家人让旁证发声；若替她永远抹去签名，她会拒绝把被保护当作无罪。此场面既是顾的阴谋推进，也是她的友情或爱情线所需的信任考验。

第十一章的白河两岸都看见对方点起烽火，并各持一封真正驿印的“先动手”命令。玩家在战斗中须守住渡桥、送达两份原信；相反命令的发出时间不同，黄蓉据此查到顾的换信人。桥上的误战能够被阻止，但背后公共仓的火已起：玩家可抢救账页、粮袋或护送守仓人，所得不同，仓本身必毁。第十二章对质时顾承认焚仓，却说“若各地都肯交权，何至于拖到今日”；主角拿出第八章补粮来自顾私仓的凭证，证明短缺并非天灾所致。顾仍带走一部分愿信他的守军，留下真正会在第三篇爆发的矛盾。

第二篇的戏剧性落在第九章与第十一章：沈槐的隐瞒确实伤害了信任，但由玩家已见的胁迫和家人处境推动；白河阻止杀戮仍付出粮仓被毁的代价。玩家能够改变谁受伤、谁愿继续同行与后续可用补给，不能让所有人永远同意自己。伙伴和恋人在面对艰难选择后拥有不同的留队、暂离与复归场景；暂离不会删除已学招式或令主线失去唯一能力。

第十三章顾并未凭一声令下控制天下，他只要卡住四条已有粮道的节点，就能迫使不同地区在同一天缺粮。第一篇受过帮助的人会带来小船、旧账或守桥的手艺；没有完成相关支线，也有普通渡工提供较慢的替代路线。第十四章玩家回到第一次被收留的客栈时，乔红绡已把桌椅搬到巷口当担架，陆青禾要把自家船拆开做临时浮桥。玩家选择先救客栈熟人或巷尾的陌生伤者，不能阻止屋梁倒塌。下一处安全地点的安静晚饭、缺了一张熟悉的桌子，比再加一场战斗更能让损失留下重量。

第十五章会盟不以“玩家演讲成功”解决分歧。郭靖与萧峰都愿护人，却对是否先攻仓有不同判断；黄蓉要求先查道路容量，令狐冲拒绝让临时队伍变成永久军令，顾军中想退出的脚夫担心家人遭报复。玩家逐一听取真实约束，定下作战次序并向各方写明若失败谁负责接应。关系好的伙伴会提出更好的备选，但不会替玩家承担全部选择。战前可与恋人、友人单独谈话，承认“我可能回家”或“我想留下”；若从未坦白，第十八章告别会显得仓促并造成真实伤害。

第十六、十七章的大战用连贯的目标表达规模：护送粮车过白河、截断北岭封关令、在归潮渡夺回信号，再进入顾守的总仓。每个战区都有与其前章人物对应的报告和后果，援军不是凭空刷出的特效。顾最后命人点燃总仓，以为没有粮的人会更快交权；他的副将面对仍在仓内的自家脚夫拒绝继续放火。玩家队伍可先开侧门救人，再断火线与顾交战；若一味攻击，战斗仍能赢，伤亡和结局证词却会不同。停战不是所有人握手言和：粮要重新分配，失踪者要查，放下武器的普通士兵也要有去处。

第十八章的华山没有把战争创伤一夜抹平。有人主张把顾的护路权交给“最能打的五个人”，也有人坚持武功强不等于有权替百姓管粮。论剑以公开规则解决武学称号之争，五席在见证人面前只承诺护路与授艺，不接管仓库。主角是否入席、恋人与友人是否同路、最终留在江湖还是回到现代，至此才真正成为自己的选择。华山观众席中会出现此前救下或失去之人的家属，让论剑承接三篇经历，而非额外附赠的一场孤立比武。

顾的失败不是单挑胜利即自动解决饥荒。第十七章末，玩家必须交回可以核验的仓单、开放三条替代粮路，并安置愿意投降的普通士兵；受害者主持公开审议。许观澜在第一篇留下的责任仍独立存在，不能因顾更坏就洗去许的伤害。战后的人物离别、恋情维系和华山分歧由前两篇累积的事实驱动。

侠客岛在第三篇作为可乘船到达的地区：有人冒其名义发出邀约，带走守渡者。玩家可到岛上核对名单，先找人或先澄清假信；无论是否调查，岛上公共岸区仍在大地图开放，战争所需信使有保底替代。第三篇新增 12 条地域支线，其中 8 条沿用原案、4 条承接探索结识的门派与人物；九派新增相遇按第 1.6 节记为 `encounter.*`，不增加支线总数。它们改变大战资源、人物命运与终局对白，不构成战争主线的必做清单。

### 7.1 华山论剑：新的五席

华山论剑发生在大战结束与补给稳定之后，不以战场功劳直接换武学称号。参会者先约定规则：公开身份、禁用伤人毒物、允许认输、伤者不被强迫出场；切磋设破招、守势与实战三个环节，裁判记录招式和胜负。候选人为已在三篇有实质出场、愿意参会且符合当前人物行程的经典高手与玩家。玩家无须先决定最终去向即可申请参会，但须完成主线修习和两次正式切磋；未达条件或自愿旁观，仍有完整论剑结局。第一篇 Demo 不涉及这套选拔。

“新五绝”是**本作这届论剑的五位胜出者**，不是原著传统五绝的复刻、跨小说官方实力排名或五种永久垄断的职务。参会者分入东、西、南、北四组，各组以切磋结果出一席；未得席者再争中席。报名人数不足时以事先公布的轮空规则处理，不靠剧情临时指定胜者。具体人物由入场资格、可重放的论剑规则与对战结果决定；剧情不预先指定某位主角必胜某位经典人物。主角可参赛或旁观；即使取得一席，若最后决定返回现代，也能在宣布名单前让出席位，由同一赛制的下一位候选人递补。参赛战绩仍被记录，最终名单始终有五人且战后可见。论剑之后五人明确表态：他们可以护路、授艺和劝止私斗，不能以“五绝”名义替别人决定粮与人生。

基础候选池为令狐冲、黄蓉、萧峰、郭靖、段誉、虚竹、任盈盈及满足修习条件的主角；黄药师、欧阳锋、一灯大师与其他已登场高手可在锚点审核通过、本人愿意且当前行程允许时申请参会或担任见证，不能自动占据席位。缺席者由已经登场并通过人物档案审核的候补参会者补足，不能临时捏造一位更强的“神秘高手”；独孤求败只存于传承记录，不进入候选池。论剑至少展示两场有具体人物立场的切磋：郭靖与萧峰以护人招式对拆，胜负由当场规则决定，战后仍能互相敬重；黄蓉与任盈盈围绕虚实和破局较量，谈及第二篇各自保护名单的理由。玩家若参会，其对手由入场名单确定。五席名单在华山现场逐一宣读并写入见闻札记，展示姓名、方位席、对阵记录和该人物战后去向。

### 7.2 最终结局与返现代

第十章的观测簿给出回返的三个条件：此世界保存的两段归潮石纹重新相合、与主角初来时对应的天象重现、跨界者本人在场。第十七章从顾占据的旧渡取回另一段石纹；其用途早在第二篇被记录，顾只把它当作稀物抵押，没有预知跨界。第十八章华山论剑期间能观测到最后一次对应天象。主角可把两段石纹带上华山，天象结束后石纹碎裂；无论选留或返，都不存在可反复开关的传送门，也不能把同伴当作可携带物品带走。

| `ending.final.stay_rebuild` 留下修路 | 决战后帮助各地建立有监督的粮路与信使规则；华山论剑后回到曾救过的地方 | 可以与愿意同行的恋人、友人继续生活，但要面对制度争论与日常劳作 |

## 8. 友情、爱情与多位恋人的叙事规则

友情线与恋爱线都有独立的情感回报。主角帮助某人，不自动换取爱情；女性人物可以主动靠近、拒绝、改变主意或继续做朋友。所有有姓名、成年且在三篇中持续互动的女性角色均列出可达恋爱路径；如果原著阶段、既有承诺或剧情选择形成严重冲突，则需先通过可信事件解除冲突，无法解除时该存档只可维持友情。路人型无姓名人群不创建承诺状态。下表十三位拟成年、持续互动的女性角色统一按容貌美丽、身材娇好的方向设计，衣着依身份、性格和行动场景各有区别。原创人物年龄是本作暂定设定；经典人物的具体年龄、原著关系和外貌依据须在参考版本与章节审核后确定。阿青单独采用《越女剑》故事结束后的本作原创延伸阶段，登场年龄设为 18 岁；原著故事阶段约十六七岁仍照实记录，不把本作年龄称为原著事实。除阿青已注明的初查文本描写外，经典人物外貌栏仅为本作视觉方向草案，不作为已核定的原著事实。黄蓉出自《射雕英雄传》、任盈盈出自《笑傲江湖》、阿朱出自《天龙八部》；其余经典人物的来源作品见[人物考据待办](./canon/CANDIDATES.md)。九位经典人物仍待逐人核验参考版本、章节、年龄依据、身份与已知事件。若某角色所选阶段未成年，则不得开放恋爱路线。

阿朱在第二篇为一批被栽赃的家属建立独立情报网，不愿每次都以“萧峰的随行者”身份被听见。萧峰理解她救人的决心，却希望与她一起追查自身未了的事；二人有一场不经主角在场的谈话，明确是继续同行还是分开完成各自目标。若分开，阿朱与主角仍需经历第三篇救援失败时的相互指责和修复，才能成为恋人；若没有分开，主角可与她建立不次于恋爱线分量的友情。无论选择，她都不能因玩家一句夸赞放弃自己的判断。

三篇中每位可恋爱角色至少有“建立信任、承认或拒绝心意、战前承诺、战后兑现或告别”四个情感节点。第一篇为相识与友情打底，第二篇给出可选择的亲密关系及其现实阻力，第三篇以战争与返现代抉择检验承诺。关键场景用人物自己做出的行动承载情绪：失去客栈后去哪里、要不要公开过去、是否愿意冒险送出家书、在回返前要不要说实话。没有只靠礼物数值触发的表白或突然变心。

玩家可同时与多位女性建立恋人关系，但必须在建立第二段关系前向已有恋人说明；每位角色分别表达接受、附条件接受或拒绝。隐瞒关系被发现会损失信任，可能退回友情，不自动触发惩罚性的争宠战。接受复数关系的人也保留个人生活与对承诺的界限；不同角色之间的同场对白承认彼此存在，不能只在主角分别约会时“看不见”其他恋人。任何组合都不因恋人数增加而叠加无上限战斗增益；恋爱与友情提供不同对白和少量条件援助，主线三篇及回返结局在无恋人存档也完整可达。

例如陆青禾与沈槐在共同送出真信之后，若两人都已各自选择与主角相爱，主角可以坦白已有承诺；她们分别决定是否接受，之后在战前会面时谈如何分担而非互相争夺主角。这个双恋人路线明确可达。黄蓉、任盈盈或阿朱的恋爱路线也能与其他愿意接受的恋人并存，但前提是她们已自主解决原有恋爱承诺、听到完整事实且本人同意；任何一人拒绝时，玩家可选择维持原承诺、退出新关系或接受友情结局，不能用高好感覆盖拒绝。

最终返回现代只允许主角一人通过。若有恋人，主角可在华山前坦白并逐一告别；对方可以难过、生气或尊重他的决定，不被写成无条件等待。多位恋人的存档分别结算每个人的关系后果，不能合成一句“众人含泪送别”。留在江湖也不自动得到所有人的终身承诺：人物可能继续自己的路，主角须以行动维持关系。

## 9. 跨篇章任务与验收

第一篇、第二篇、第三篇各 6 个短主线关口，共 **18 个主线任务**；地域支线分别为 14、12、12 条，共 38 条，另有第一篇 8 条伙伴关系任务，合计 **46 条可选支线任务**。十三位拟按成年阶段持续互动的女性候选，其感情事件是独立关系节点，进入对话图与关系事实，暂不把每次谈心拆成一条任务增加日志负担；阿青新增的第三篇节点须在 M4 排产。扩展人物与九派的 `encounter.*` 是地区相遇事件而非第 47 条支线；事件数量、对白、22 处势力地图及资产仍增加，须在 M4 排产和 M5 复估。新增经典人物与门派的参考版本、章节、年龄、身份和已知事件仍待逐项核验；若核验发现提议中的恋爱前提不成立，先调整原创事件和锚点选择并重新评估可达路线，不偷改原著年龄、核心身份和已有承诺；阿青的本作 18 岁延伸阶段须单列改编依据与成本。

篇章切换由当前篇终章任务完成后触发：先结算战斗、唯一物、人物位置、承诺和**已明确提示时限的已接取支线**，再写入 `ArcId`、当前世界关口 `ChapterId` 与下一篇可用区域，最后在安全地点提供自动保存。`ArcId` 依次为 `arc.part1`、`arc.part2`、`arc.part3`，`ChapterId` 使用 `chapter.01` 至 `chapter.18` 的稳定 ID，但不能以其数值推断并行组每个任务都已完成；完成事实逐任务保存。可返回的旧区域依旧存在，未接取地区故事保留合理的后续入口，已知过时救援支线明确结算并解释。三篇共用关系、成长和物品；敌方强度按世界关口与玩家成长预算调整。第二、三篇新地区的支线和恋爱事件不能成为主线证据的唯一来源。

剧情验收须覆盖：第一篇 02→03 与 03→02、第二篇 08/09/10 的代表性不同顺序、第三篇 14→15 与 15→14，三篇都在缺席可选门派人物时取得保底证据；第一篇三种账簿处置各进入第二篇，第二篇白河两种救援次序各进入第三篇，第三篇两种作战次序均能完成大战。主角参与或旁观论剑都能评出五个席位；留江湖两种路线及独自返现代均可达。至少检查无恋人、单恋人、多位恋人、已告知和未告知回返意向的存档，人物对白、分手或承诺、队伍占用与存档事实一致。关键情绪场景通过试玩核对动机与铺垫，不把“对白数量多”当作戏剧性验收。
