# M1 战斗原型试玩

版本：2026-09-30 · 对应[开发计划 M1](../DEVELOPMENT_PLAN.md#m1第二阶段内部战斗与成长原型w3w6) · 规则版本 2

目的是回答 M1 验收里只能靠人判断的问题：三种流派的差异玩家能不能用自己的话说出来；有没有“永远普攻即可”“无限控制”“无限回内”；首领的预兆看不看得懂、节奏是否拖沓。画面沿用已验收的 M0 战斗页，**出手与受击是补间占位，正式骨骼动作未做**，不必评价动作。

## 启动

1. `$env:GODOT_BIN = '<Godot .NET 编辑器路径>'; ./tools/scripts/export-windows.ps1`（会先生成内容包）。
2. 运行 `build/windows/WuxiaWorld.exe` → 标题页进入场景目录 → 末尾“战斗原型（M1）”。
3. 配置页：← / → 选遭遇（押运队冲突 / 旧渡水门），Q / E 选主角流派，Enter 开战。

## 操作

| 键 | 作用 |
|---|---|
| A、1–6 | 普通攻击 / 第 1–6 招（卡面灰掉时写着原因：冷却、内力不足等） |
| Tab、← → | 换目标；鼠标悬停也可换，点目标两次施展 |
| Enter | 施展 |
| D / R | 防御 / 调息 |
| I | 物品（再按换一种，Enter 使用，Esc 取消） |
| S | 换位（Tab 选位置） |
| X | 撤退（剧情战不可） |
| F / Space / P / L | 2 倍速 / 跳过当前播放 / 自动战斗 / 展开日志 |
| 结算页 R / N / B | 同种子重来 / 换种子再战 / 重新配置 |

选中的目标会沿轮廓描边；横扫一排、穿透一列（穿林剑）等群体招式会在地面圈出整片范围。顶栏下方的预估框写着命中率、伤害区间（不含与含暴击）、削架势以及“将打出破绽”“可打断对方蓄力”“护院会代受”等提示；人物头顶的圆印是醒目标记：“蓄”为首领在蓄力、“危”为被首领的蓄力招盯上、“闸”为水门机关（右下角是水位）。每人头顶只有一条血条和其下一道细金线（架势，破绽时变红）。鼠标停在人物、血条或圆印上，人物右侧会弹出信息小窗，列出数值、意图全文和各状态说明；悬停我方势 / 敌方势、“本轮行动顺序”和各人印鉴可看规则说明。

## 建议试法

1. 押运队冲突：2026-10-01 起为满编 6 名敌人，用来看站位分布；两人队基本打不过，可按 P 自动看过程。
2. 旧渡水门：唐守亭第 2 轮起蓄力“水门冲击”，下一轮横扫前排——试试剑术用破势剑破架势打断、内功用点穴手（首领要中两次）、拳掌在前排防御招架；水门机关每 3 次行动开闸一次，先拆机关会让唐守亭失去掩护；半血时有护院增援；敌方势攒满 50（顶栏变色并标 ⚠）时，唐守亭会蓄力“回澜钩”钩一人，被盯上的人头顶出现“危”，可用护身掌替他挡、换位、防御或打断。第三名同行者是占位剪影，正式版由经典人物援手。
3. 同一种子（R）换打法重来，比较结果。
