# M0 视觉 Demo 交付核对

M0-07 交付物：展示包启动方式、操作说明、截图清单、每页核对要点和反馈表。目的是请用户确认画风、人物比例、探索视角与战斗视角（[开发计划 M0](../DEVELOPMENT_PLAN.md#m0第一阶段场景与-ui-视觉-demow1w2)）。页面内容全部为固定样例，**不代表玩法已实现**；标为“占位”或“待制作”的部分不在本轮验收画风之列。

## 1. 启动

| 项目 | 说明 |
|---|---|
| 展示包 | `build/windows/WuxiaWorld.exe`（同目录 `WuxiaWorld.pck` 与 `data_WuxiaWorld.Game_windows_x86_64/` 须一起拷贝；`licenses/` 为字体许可与资产台账） |
| 重新生成 | `./tools/scripts/export-windows.ps1`（需 `GODOT_BIN`，见 [tools/README.md](../../tools/README.md)） |
| 系统 | Windows 11 x64；窗口默认 1920×1080 逻辑画布，按窗口缩放 |
| 截图 | `./tools/scripts/capture-review.ps1 -Resolution 1920x1080,2560x1440` 用导出包逐页截图到 `build/review/m0/<分辨率>/`（本地产物，不入库） |

启动后进入标题页，任意键进入主菜单；“继续旅程”进入**场景目录**（2026-10-02 起改由主菜单“场景目录”进入，“继续旅程”读最近存档），12 个展示页均可直接进入。任何页面按 `Esc` 回标题（弹层打开时先关弹层）。

## 2. 全局操作

| 页面 | 操作 |
|---|---|
| 标题 / 目录 | 方向键或鼠标选择，`Enter` 确认，`Esc` 返回 |
| 探索（城镇、客栈、山路、HUD） | `WASD` / 方向键行走，`Shift` 快走，`E` 交互（城镇客栈门口 ↔ 客栈大堂门口可互相进出），滚轮缩放，`M` 大地图，`C` / `I` / `J` 人物 / 行囊 / 札记 |
| 大地图 | 滚轮缩放、拖动平移，`Tab` 跳选地标，`1`–`3` 骑马 / 马车 / 渡船，`Enter` 启程（行进预览），点空白处或 `Esc` 关面板 |
| 对话 | `Enter` / 空格 / 点击推进，数字键选项，`L` 对话记录，`H` 隐藏界面 |
| 战斗 | `1`–`6` 选招，`Tab` 换目标，`Enter` 播放攻击预览，`V` 切换胜利结算 |
| 人物 / 行囊 / 札记 / 设置 | `Q` / `E` 切换分区，`PgUp` / `PgDn` 切页签 |

## 4. 人物形象一致性

探索与战斗共用同一张 AI 全身样稿（`game/assets/art/figure/`），立绘另行制作：

| 人物 | 立绘 | 探索 / 战斗形象 | 出现页面 |
|---|---|---|---|
| 主角（青年男子、本地短打） | 待制作（角色页暂以全身样稿代替） | hero·66 | 探索三页、HUD、战斗、角色页 |
| 陆青禾 | v1 半身（`lu_qinghe_v3_from505_7`） | lu_qinghe·33 | 标题、对话、探索三页、战斗 |
| 乔红绡、店小二、茶客 | 无 | 各 1 张 | 客栈大堂 |
| 唐守亭、押运打手 | 无 | 各 1 张（打手两名共用） | 战斗 |

核对：同一人物在立绘、探索、战斗三处的服装配色是否一致，年龄感与身份是否相符。
