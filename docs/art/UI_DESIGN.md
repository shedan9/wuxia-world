# 游戏界面设计规范：青绿·玉版

版本 2026-09-24，适用于 M0 视觉 Demo 起的全部界面。配色与尺寸的语义定义以[架构文档 10.4 节](../ARCHITECTURE.md#104-ui-规范与关键界面)为准，本文件说明视觉语言、组件、各界面版式、动效与输入。实现集中在 `game/scripts/presentation/`（见第 9 节）。

## 1. 为什么重做

第一版界面把网页后台的做法搬进了游戏：纯色底、白色卡片、细线按钮、没有背景与人物，页面像表单。用户看过后认为“粗糙得没法看”。本次按游戏界面的做法重做，依据下面五条原则：

1. **画面先于面板。** 任何界面背后都有场景：标题页是清晰的山水与人物，菜单是虚化压暗的同一片山水，战斗与探索叠在场景上。不出现空白纯色底。
2. **材质与纹饰表达层级。** 用“玉版”（浅色纸面）与“潭影”（深色玻璃）两种面区分阅读区与操作区，用金泥角饰、菱形与双线框表达“这是一件器物”，而不是靠边框粗细。
3. **人物是界面的主角。** 标题页、对话、人物页给立绘大面积位置；没有立绘的人物用明确的占位并标注待制作。
4. **每个状态都可见。** 悬停、选中、键盘焦点、禁用、冷却各有不同的形与色；焦点统一为控件外侧的金泥折角，不只靠颜色。
5. **有节奏的动效。** 入场依次浮现，切换经玄潭色幕淡出淡入，选中项有墨痕铺开；时长短，可整体关闭。

## 2. 视觉语言

### 2.1 两种面

| 面 | 用途 | 构成 |
|---|---|---|
| 玉版 `SheetPanel` | 人物、行囊、札记、设置等阅读与表单页 | 水白→选中底竖向渐变，12 px 切角，石绿外框 + 7 px 内衬线（双线框），四角金泥回纹，玄潭柔和投影 |
| 潭影 `DarkPanel` | 存档弹层、对话记录、战斗指令区、结算 | 深潭→玄潭竖向渐变，其余同玉版 |
| 薄玻璃 `GlassPanel` | HUD、提示条、行动顺序、日志 | 玄潭 62–78% 透明，细框，无角饰，不抢画面 |

### 2.2 色彩

沿用架构文档 10.4 的青绿山水语义色，本次补充两色：

| 语义 | 值 | 规则 |
|---|---|---|
| 金泥 `Gilt` | `#D2BC82` | 只用于角饰、菱形标记、焦点折角、分隔线正中的菱形、稀有度与深色面上的短标签；对深潭 5.9:1、对玄潭 8.1:1；不作大面积底色，不作玉版正文 |
| 玄潭 `Abyss` | `#0B2A30` | 深色渐变底端、遮罩、投影、键帽文字；深底正文对其 13.9:1 |

- 杏红 `Warm` 仍是唯一的红色系，只用于气血、下降、敌方意图与警示。
- 内力条改为石青渐变（原为竹青），与“增益”的竹青分开；势与经验用金泥暗色。
- 所有状态同时给符号：▲ 提升、▼ 下降/破绽、● 持续伤害、◆ 防御/当前、⚠ 意图、✓ 已完成、○ 进行中。

### 2.3 字体与字号

| 层级 | 字体 | 逻辑像素 | 例 |
|---|---|---|---|

| 页标题 | 霞鹜文楷 | 36–44 | 页名、存档标题 |

| 次级 | 思源黑体 | 16–20 | 说明、键帽旁文字 |

### 2.4 间距与网格

逻辑画布 1920×1080，间距阶梯 8 / 16 / 24 / 32 / 48。全屏界面四周安全边距 40–56；菜单外框左右 56；玉版内边距 40×22。16:10 与 21:9 下左侧内容锚左、立绘与右侧信息锚右，中间由背景填充。

## 3. 纹饰与组件

全部由 `OrnateBox`（`Ui/OrnateBox.cs`，继承 `StyleBox`，运行时用 RenderingServer 绘制）生成，不依赖贴图，4K 下仍清晰。

| 纹饰 | 画法 | 用在 |
|---|---|---|
| 切角 | 八边形轮廓，4–14 px | 所有面板与按钮 |
| 双线框 | 外框 + 内缩 3–8 px 的淡线 | 玉版、潭影、主按钮、姓名牌 |
| 回纹角 `Hook` | 角上 L 形折线，内折一道小钩，两端各一粒菱形 | 玉版、潭影、卡片悬停、对话框、小地图 |
| 折角 `Bracket` | 只有 L 形折线，可外扩 | 键盘焦点、战斗目标、小插框 |
| 菱形分隔 `DiamondRule` | 两端渐隐的细线，正中金泥菱形；小节标题后缀版菱形在左 | 页内分节 |
| 墨痕 | 自左向右渐隐的石青横条，左端金泥菱形 | 标题菜单选中、对话选项 |
| 页名章 `Seal` | 石青渐变小方章，金泥边，竖排书法字 | 页名、存档、轮次、地点 |
| 键帽 `KeyHint` | 浅玉色小切角块，玄潭字，底边一道暗线 | 所有按键提示 |
| 字形印鉴 `Glyph` | 切角玉牌，类别色描边与内衬，书法单字 | 物品、招式、队伍头像的 M0 占位 |

## 4. 背景与氛围

`assets/shaders/landscape.gdshader` 程序化绘制青绿山水，作为标题页背景、菜单虚化底，以及正式场景美术完成前的占位远景：

- 天空：石青淡蓝到水白的竖向渐变，右上日轮与光晕，横向流云缓慢右移。
- 四重山：折叠噪声加低频包络得到成簇高峰；山顶石青、山腰石绿，右坡迎光、左坡背光的硬边明暗，迎光坡山脊一道亮边，近山带赛璐璐山脊描线；远山雾化（大气透视），山间三层流雾各自漂移。
- 江面：倒映天色，横向波纹与日下碎光；左下近岸剪影作前景。
- 参数：`defocus`（0 清晰 / 1 虚化，同时放宽边缘、降低细节）、`veil`（玄潭遮罩）、`left_wash`（左侧提亮，给深色文字留读字区）、`parallax`（鼠标视差）、`world_seed`（山形种子，用于存档缩略图区分地点）。
- `Backdrop` 控件封装着色器，并加飘落柳叶粒子（运行时生成的叶形，水白到石绿）。`Backdrop.Clear()` 用于标题页，`Backdrop.Veiled()` 用于菜单，`Backdrop.Still()` 用于缩略图。

## 6. 动效与声音

| 场合 | 动效 | 时长 |
|---|---|---|
| 场景切换 | 玄潭色幕淡出 → 切换 → 淡入 | 0.18 + 0.32 秒 |
| 面板入场 | 淡入并上浮 10–24 px 或侧移 24–60 px，缓出三次曲线 | 0.32 秒 |
| 列表 / 菜单入场 | 依次入场，间隔 0.03–0.06 秒 | — |
| 焦点移动 | 状态框即时切换 | 0 |
| 提示呼吸 | 透明度往复（按任意键、交互提示、目标框、继续菱形） | 1–2.2 秒一周期 |
| 立绘 | 入场侧移淡入；标题页呼吸 0.6% 纵向缩放 | 0.9 / 4.8 秒 |
| 命中 | 目标闪白 0.25 秒 + 四次横抖，伤害数字上浮 0.8 秒后淡出 | — |

截图模式与“减少动效”时 `Motion.Enabled = false`，所有动效直接落到终态。

声音挂点（音频资产未制作，名称先行固定）：`ui.move`、`ui.confirm`、`ui.cancel`、`ui.tab`、`ui.page`、`ui.toast`、`ui.denied`（点禁用项）、`dialogue.advance`、`battle.select`、`battle.hit`、`battle.victory`。

## 7. 输入与焦点

- 鼠标悬停即取得焦点，键盘与鼠标共用同一个“当前项”；每页进入时焦点落在第一项。
- 通用键：方向键 / Tab 移动，Enter / 空格确认，Esc 返回；Q / E 换分区，PgUp / PgDn 换子页签。
- 界面专用：对话 1–9 选项、L 记录、H 隐藏；战斗 1–6 选招、Tab 换目标、A / D / R / I / S / X 基础行动；探索 E 交互、C / I / J / M 打开对应页。
- 每个界面底部用键帽写出当前可用按键；手柄图标在接入手柄后替换键帽文字。

## 8. 可读性与辅助

- 文字对比度按 WCAG 相对亮度实测，正文至少 4.5:1（数值见架构文档 10.4 与第 2.2 节）。浮在山水上的文字必须有底：薄玻璃、左侧提亮或描边，三者至少其一。
- 状态不只靠颜色：符号 + 名称 + 颜色。禁用项写明原因（提示或旁注）。
- 设置页提供字体缩放、字幕速度、文本立即显示、色觉辅助、屏幕震动关闭、减少动效和战斗加速。
