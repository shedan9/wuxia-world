# 游戏界面设计规范：绢本青绿

版本 2026-09-24（第三版），适用于 M0 视觉 Demo 起的全部界面。配色与尺寸的语义定义以[架构文档 10.4 节](../ARCHITECTURE.md#104-ui-规范与关键界面)为准，本文件说明视觉语言、组件、各界面版式、动效与输入。实现集中在 `game/scripts/presentation/`（见第 9 节）。

## 1. 为什么重做

第一版界面把网页后台的做法搬进了游戏：纯色底、白色卡片、细线按钮、没有背景与人物，页面像表单。用户看过后认为“粗糙得没法看”。第二版“青绿·玉版”改为游戏界面的做法（场景垫底、纹饰、立绘、动效），用户认可整体性，但指出两个严重问题和几处缺陷：

- **颜色太单调，到处都一样。** 背景是青绿山水，面板是深潭青与水白，按钮与分隔线又是石青、石绿——整屏只有一个色相，面板与背景、阅读面与操作面分不开。
- **线条太规整，没有艺术感。** 1 像素细线、切角矩形、直角折角，像没设计过的草图；在 1600×900 等缩放窗口下细线还会发虚。
- **缺陷：** 存档弹层内容超出面板高度，压到标题页底栏；部分边框发虚；标题页立绘上下“呼吸”一顿一顿。

第三版“绢本青绿”保留第二版的结构与五条原则，改两件事：

1. **颜色取自青绿山水画本身。** 青绿山水从来不是只有青绿：画在暖黄的绢上，赭石打底、石青石绿罩染，泥金勾线，朱砂钤印。山水背景保持青绿；界面改用绢色作阅读面、黛色作深色面、朱砂作印章与选中点、赭石与泥金作笔线，冷景暖面互衬。不同界面再用时辰区分：标题与探索为晨昼，战斗为黄昏。
2. **线条改为笔触。** 面板与按钮的框是四笔手绘界格（起笔顿、收笔出锋、出角有余锋、带飞白），角饰是泥金卷云，选中是一笔刷开的色带，面板边缘是绢边的毛边，面上有绢纹和一角淡彩晕染。印章带印泥的缺墨与毛边。全部程序化绘制，4K 下仍清晰。

原则不变：

1. **画面先于面板。** 任何界面背后都有场景，不出现空白纯色底。
2. **材质与纹饰表达层级。** 绢本（暖）与黛本（冷）区分阅读区与操作区，笔框、卷云角与印章表达“这是一件器物”。
3. **人物是界面的主角。** 标题页、对话、人物页给立绘大面积位置；没有立绘的人物用明确的占位并标注待制作。
4. **每个状态都可见。** 悬停、选中、键盘焦点、禁用、冷却各有不同的形与色；焦点统一为控件外侧的泥金折角，不只靠颜色。
5. **有节奏的动效。** 入场依次浮现，切换经色幕淡出淡入，选中项一笔刷开；时长短，可整体关闭。

## 2. 视觉语言

### 2.1 几种面

| 面 | 用途 | 构成 |
|---|---|---|
| 绢本 `SheetPanel` | 人物、行囊、札记、设置等阅读与表单页 | 绢→绢影竖向渐变、毛边、赭石绢纹；左上与右下一团石绿淡彩晕染；赭石四笔界格 + 内衬淡笔；四角泥金卷云；玄黛下落投影 |
| 黛本 `DarkPanel` | 存档弹层、对话框、战斗指令区、结算 | 黛→玄黛竖向渐变、毛边、白色细绢纹、石青晕染；泥金笔框 + 内衬淡笔；四角泥金卷云 |
| 薄墨 `GlassPanel` | HUD、提示条、行动顺序、日志 | 玄黛 60–74% 透明的一片毛边色块，顶边一道淡泥金笔线，无框无角饰，不抢画面 |
| 印 `SealPanel` | 页名章、姓名章、轮次章、标题落款 | 朱砂渐变、毛边、印泥缺墨（绢色细纹），内框一笔绢色 |

### 2.2 色彩

语义色见[架构文档 10.4 节](../ARCHITECTURE.md#104-ui-规范与关键界面)。用色分工：

| 颜色 | 用在 | 不用在 |
|---|---|---|
| 青绿（石青、石绿） | 山水背景、主按钮、选中刷痕、内力条、我方描边 | 大面积面板底 |
| 绢、绢影 | 阅读面、键帽、小地图底、字形印鉴底 | 深色面上的正文 |
| 黛、玄黛 | 深色面、遮罩、投影、转场色幕 | — |
| 朱砂 | 印章、选中项左端朱点、绢面子签下划线、列表选中竖笔、通知竖笔 | 数值状态（那是杏红） |
| 赭石 | 绢面笔框、分隔笔线、界格、山脚 | 正文 |
| 泥金 | 卷云角、菱形、焦点折角、深面笔框与短标签 | 大面积底色、绢面正文 |
| 杏红 | 气血、下降、敌方意图与警示 | 纹饰 |

- 一屏之内冷暖都要有：冷的山水 + 暖的绢面或朱砂印。深色面（存档、对话、战斗）至少有一方朱砂印或泥金卷云。
- 时辰：`Backdrop` 的 `mood` 0 为晨昼（暖绢色天际、石青天顶），1 为黄昏（琥珀天际、黛蓝天顶、山色压暗偏紫）；战斗用黄昏，对话为午后（0.3），存档缩略图按存档时辰取值。
- 所有状态同时给符号：▲ 提升、▼ 下降/破绽、● 持续伤害、◆ 防御/当前、⚠ 意图、✓ 已完成、○ 进行中。

逻辑画布 1920×1080，间距阶梯 8 / 16 / 24 / 32 / 48。全屏界面四周安全边距 40–56；菜单外框左右 56；绢本内边距 40×22。16:10 与 21:9 下左侧内容锚左、立绘与右侧信息锚右，中间由背景填充。

## 3. 纹饰与组件

全部由 `OrnateBox`（`Ui/OrnateBox.cs`，继承 `StyleBox`）与 `Brushwork`（`Ui/Brushwork.cs`）运行时绘制，不依赖贴图，4K 下仍清晰。项目开启 4× 2D MSAA，笔画边缘在缩放窗口下不发虚；不再使用 1 像素细线。

| 纹饰 | 画法 | 用在 |
|---|---|---|
| 笔画 `Stroke` | 沿折线生成三角形带：起笔由 0.4 升到满宽，行笔粗细随噪声在 0.7–1.3 倍间起伏，收笔落到 0.12 出锋；可加 4 道长短不一的细丝做飞白 | 所有笔框、分隔、竖笔、折角 |
| 笔框 `Brush` | 四边各一笔，略带弧度；起笔在角外、收笔越过下一个角（余锋，`Overshoot` 控制，上下紧挨的卡片取小值） | 面板、按钮、签、卡片 |
| 毛边 `Ragged` | 轮廓每约 10 像素取一点，按噪声内外错开 1–2 像素 | 面板、按钮、印章、键帽 |
| 绢纹 `Grain` | 可平铺的绢丝横纹 + 纵向弱纹 + 细颗粒，按面着色 | 绢本（赭石）、黛本（白）、印章（绢色，作缺墨） |
| 晕染 `Wash` | 左上、右下各一团中心浓边缘散的淡彩，边缘不齐 | 绢本、黛本、对话框、人物画框 |
| 卷云角 `Cloud` | 沿一边行笔入角，在角内打一个向内收的卷；另一边一短笔止于卷旁，两粒墨点收尾 | 主要面板四角、卡片悬停与选中 |
| 折角 `Bracket` | 两笔自角点向外出锋，可外扩 | 键盘焦点、战斗目标、小插框 |
| 刷痕 `Swipe` | 自左向右一笔刷过的色带：左端饱满，上下缘不齐，向右收窄碎开，尾部几道断丝 | 标题菜单、列表行、对话选项、卡片的悬停与选中 |
| 分隔 `DiamondRule` | 两笔自中间向两端出锋的淡墨线，正中泥金菱形压一粒朱砂；小节标题后缀版菱形在左 | 页内分节 |
| 印章 `Seal` / `SquareSeal` | 朱砂印泥，毛边、缺墨，内框一笔绢色；竖排或四字两行 | 页名、姓名、轮次、存档、标题落款 |
| 键帽 `KeyHint` | 绢色小块，毛边，底边一笔赭石，墨色字 | 所有按键提示 |
| 字形印鉴 `Glyph` | 绢底毛边玉牌，类别色笔框与内衬、类别色绢纹，书法单字 | 物品、招式、队伍头像的 M0 占位 |

按钮状态（`UiTheme`）：

## 4. 背景与氛围

`assets/shaders/landscape.gdshader` 程序化绘制青绿山水，作为标题页背景、菜单虚化底，以及正式场景美术完成前的占位远景：

- 天空：石青天顶到暖绢色天际的竖向渐变，右上日轮与光晕，横向流云缓慢右移。
- 四重山：折叠噪声加低频包络得到成簇高峰；山顶石青、山腰石绿、山脚染赭石（越近越显，即青绿山水“赭石打底、青绿罩染”），右坡迎光、左坡背光的硬边明暗，迎光坡山脊一道亮边，近山带赛璐璐山脊描线；远山雾化（大气透视），山间三层流雾各自漂移。
- 江面：倒映天色，横向波纹与日下碎光；左下近岸剪影作前景。
- 参数：`defocus`（0 清晰 / 1 虚化）、`veil`（玄黛遮罩）、`left_wash`（左侧提亮，给深色文字留读字区）、`parallax`（鼠标视差）、`world_seed`（山形种子）、`mood`（时辰：0 晨昼，1 黄昏；天色、日色、雾色、山色一起变）。
- `Backdrop` 控件封装着色器，并加飘落柳叶粒子（水白到石绿，夹几片赭黄，黄昏时更多）。`Backdrop.Clear()` 用于标题页，`Backdrop.Veiled()` 用于菜单，`Backdrop.Dusk()` 为黄昏，`Backdrop.Still()` 用于缩略图。

### 5.8 通用弹层与提示——规格

- 确认框：居中黛本小面板，标题 + 一句后果说明，“确认”主按钮在右、“取消”在左；不可逆操作（丢弃、覆盖存档、回到标题）必须经确认，Esc 等于取消。
- 提示（Tooltip）：黛色毛边小框 + 折角；物品与招式提示含名称、类别、数值与对比 ▲▼。
- 加载：玄黛底，右下柳叶转动加“行路中……”，左下一句见闻札记摘录；不显示百分比进度条以外的假数据。
- 章节标题卡：黑场后标题字写章节名，页名章写“第一章”，淡入停留 2 秒。

## 6. 动效与声音

| 场合 | 动效 | 时长 |
|---|---|---|
| 场景切换 | 玄黛色幕淡出 → 切换 → 淡入 | 0.18 + 0.32 秒 |
| 面板入场 | 淡入并上浮 10–24 px 或侧移 24–60 px，缓出三次曲线；只叠加逐渐归零的位移，容器中途重排时跟随新位置 | 0.32 秒 |
| 列表 / 菜单入场 | 依次入场，间隔 0.03–0.06 秒 | — |
| 焦点移动 | 状态框即时切换 | 0 |
| 提示呼吸 | 透明度往复（按任意键、交互提示、目标框、继续菱形） | 1–2.2 秒一周期 |
| 立绘 | 入场侧移淡入；标题页随鼠标视差，不做缩放呼吸（极慢的亚像素缩放会让线稿逐像素爬动、看起来一顿一顿，也会拉伸五官） | 0.9 秒 |
| 命中 | 目标闪白 0.25 秒 + 四次横抖，伤害数字上浮 0.8 秒后淡出 | — |

截图模式与“减少动效”时 `Motion.Enabled = false`，所有动效直接落到终态；截图加 `--motion --settle=<帧数>` 可保留动效截取中途画面。

声音挂点（音频资产未制作，名称先行固定）：`ui.move`、`ui.confirm`、`ui.cancel`、`ui.tab`、`ui.page`、`ui.toast`、`ui.denied`（点禁用项）、`dialogue.advance`、`battle.select`、`battle.hit`、`battle.victory`。

## 7. 输入与焦点

- 鼠标悬停即取得焦点，键盘与鼠标共用同一个“当前项”；每页进入时焦点落在第一项。
- 通用键：方向键 / Tab 移动，Enter / 空格确认，Esc 返回；Q / E 换分区，PgUp / PgDn 换子页签。
- 界面专用：对话 1–9 选项、L 记录、H 隐藏；战斗 1–6 选招、Tab 换目标、A / D / R / I / S / X 基础行动；探索 E 交互、C / I / J / M 打开对应页。
- 每个界面底部用键帽写出当前可用按键；手柄图标在接入手柄后替换键帽文字。

## 8. 可读性与辅助

- 文字对比度按 WCAG 相对亮度实测，正文至少 4.5:1（数值见架构文档 10.4 与第 2.2 节）。浮在山水上的文字必须有底：薄墨、左侧提亮或描边，三者至少其一。
- 状态不只靠颜色：符号 + 名称 + 颜色。禁用项写明原因（提示或旁注）。
- 设置页提供字体缩放、字幕速度、文本立即显示、色觉辅助、屏幕震动关闭、减少动效和战斗加速。
