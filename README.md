# 武侠世界

高清 2D 单机武侠回合制养成 RPG。主角从现代穿越至一个架空江湖，所有金庸角色同处一个年代；不同作品人物的相遇、合作、冲突与战斗，以及友情、爱情和角色成长共同推动剧情。

角色年龄与身份原则上以各自小说主要剧情阶段为准，不因时间兼容而改龄或改换核心身份；统一世界的年表与事件安排服从这一约束。阿青单独采用《越女剑》故事结束后的原创延伸阶段，本作以 18 岁登场；原著故事阶段约十六七岁，不把本作年龄冒称原著设定。

当前进度：**M0 视觉 Demo 已于 2026-09-30 经用户验收**（“绢本青绿”界面、三类探索布景、大地图、战斗页等 12 个展示页，画风与视角全部认可），现进入 M1 战斗与成长原型。M1 已完成确定性战斗规则内核（`src/`：轮次与阵位、伤害层次、架势与破绽、反应、点穴与免控、首领蓄力预兆、遭遇阶段、AI、命令记录与重放）、第一章战斗内容（`content/`：主角剑术 / 拳掌 / 内功三流派 12 招、3 门心法、押运队与唐守亭旧渡水门机制战）、内容编译器、战斗模拟器，以及场景目录末尾可进入的“战斗原型（M1）”页（结算来自内核，动作为补间占位）。用户已于 2026-10-01 试玩战斗原型，确认按当前打法推进，并把刀、枪、弓三类兵器排入 M4；正式骨骼动作与 AI 配音选型尚待进行。M1 期间已提前完成 M2 的世界规则层：世界状态、条件与效果、任务状态机、对话图执行、地区事件与人物占用、旅行与战斗结算事务、带备份回退与迁移的文件存档，以及第一章四张地图、主线与失踪渡工支线和 104 句对白第一稿（不设旁白，场景与动作写成演出提示；心里话只限主角、不配音）（未锁稿）；规则测试共 88 项，其中第一章走查覆盖全部同行者、副页与支线组合。探索、对话、任务札记与存读档界面尚未接到这套规则，**游戏内还不能实际游玩第一章**。进度与验证记录见[开发计划](./docs/DEVELOPMENT_PLAN.md)的 M0、M1、M2 进度记录。目标平台仅 Windows x64。

## 工程结构

| 路径 | 内容 |
|---|---|
| `game/` | Godot 4.7.2 .NET 工程；入口 `scenes/boot/Boot.tscn` → M0 场景目录 |
| `src/` | `Domain` / `Application` / `Infrastructure` 规则类库（M1：战斗内核、战斗会话、内容加载与校验；M2：世界规则、游戏会话、存档） |
| `content/` | 手工维护的 JSON 内容源（含逐章对白 `content/dialogue/`）；`dotnet run --project tools/ContentCompiler` 校验并生成 `game/generated/content` |
| `tools/` | 构建导出脚本与内容、战斗、配音工具 |
| `tests/` | 测试项目（xUnit，M1 锁定版本）：`dotnet test tests/Domain/WuxiaWorld.Domain.Tests` |
| `art_source/`、`voice_source/` | 美术与配音源文件（Git LFS） |

开发环境：.NET SDK 10.0.401（`global.json` 锁定补丁级前滚）、Godot 4.7.2 .NET（`4.7.2.stable.mono`）编辑器及同版导出模板、Git LFS；该组合已于 2026-09-23 在 Windows 11 上完成构建与导出启动验证。两台开发机均可用 winget 安装：`winget install --id Microsoft.DotNet.SDK.10 --version 10.0.401 -e`、`winget install --id GodotEngine.GodotEngine.Mono --version 4.7.2 -e`；导出模板从 Godot 官方发布页下载 `Godot_v4.7.2-stable_mono_export_templates.tpz`，解压 `templates/` 到 `%APPDATA%\Godot\export_templates\4.7.2.stable.mono`；并把编辑器路径设为用户环境变量 `GODOT_BIN`。用编辑器打开 `game/project.godot` 运行；导出见 [tools/README.md](./tools/README.md)。

当前方案：Godot .NET + C#，暂定斜俯视高清探索、独立侧视回合战斗。

三篇故事均为待制作的原创游戏剧情设计，尚非已实现内容。第一篇结尾是阶段性处置，完整游戏在第三篇大战和华山论剑后收束；主角其中一个结局可独自返回现代。具名成年女性角色设有可选择的恋爱路径，可在彼此知情同意下拥有多位恋人。登场人物的原著剧情阶段、年龄与身份依据需在制作前逐项核验；公开发行所需内容授权也尚未确认。

角色采用 AI 配音，由人工试听修整，开发期生成并随游戏包离线播放。角色音色固定，供应商通过小样比较后选定。

1. 第一阶段：交付可切换场景与主要 UI 的 Windows 视觉 Demo，使用样例数据核对画风、人物比例和视角；可附少量配音试听，不阻塞视觉交付。
2. 用户认可画风与视角后，第二阶段交付约 60 分钟“相遇—成长—战斗—选择”玩法 Demo，主线对白全配音并加入关键战斗语音。
3. 再依据试玩反馈制作三篇连续故事，同一存档跨篇推进，最终交付大战、华山论剑和完整结局。
