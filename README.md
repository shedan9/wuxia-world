# 武侠世界

高清 2D 单机武侠回合制养成 RPG。主角从现代穿越至一个架空江湖，所有金庸角色同处一个年代；不同作品人物的相遇、合作、冲突与战斗，以及友情、爱情和角色成长共同推动剧情。

角色年龄与身份原则上以各自小说主要剧情阶段为准，不因时间兼容而改龄或改换核心身份；统一世界的年表与事件安排服从这一约束。阿青单独采用《越女剑》故事结束后的原创延伸阶段，本作以 18 岁登场；原著故事阶段约十六七岁，不把本作年龄冒称原著设定。黄蓉、阿朱经用户决定同样以 18 岁登场（原文分别约十五岁、十六七岁），保留各自原著阶段的身份与经历，属标注的本作改编；第一章三位经典人物的剧情锚点见[锚点档案](./docs/canon/ANCHORS.md)。

当前进度：**M0 视觉 Demo 已于 2026-09-30 经用户验收**（“绢本青绿”界面、三类探索布景、大地图、战斗页等 12 个展示页，画风与视角全部认可），现进入 M1 战斗与成长原型。M1 已完成确定性战斗规则内核（`src/`：轮次与阵位、伤害层次、架势与破绽、反应、点穴与免控、首领蓄力预兆、遭遇阶段、AI、命令记录与重放）、第一章战斗内容（`content/`：主角剑术 / 拳掌 / 内功三流派 12 招、3 门心法、押运队与唐守亭旧渡水门机制战）、内容编译器、战斗模拟器，以及场景目录末尾可进入的“战斗原型（M1）”页（结算来自内核，动作为补间占位）。用户已于 2026-10-01 试玩战斗原型，确认按当前打法推进，并把刀、枪、弓三类兵器排入 M4；正式骨骼动作与 AI 配音选型尚待进行。M1 期间已提前完成 M2 的世界规则层：世界状态、条件与效果、任务状态机、对话图执行、地区事件与人物占用、旅行与战斗结算事务、带备份回退与迁移的文件存档，以及第一章四张地图、主线与失踪渡工支线和 104 句对白第一稿（不设旁白，场景与动作写成演出提示；心里话只限主角、不配音）（未锁稿）；规则测试当时 91 项，其中第一章走查覆盖全部同行者、副页与支线组合。2026-10-02 起探索、对话、任务札记、存读档与剧情战已接到这套规则：标题页“新的旅程”即可在游戏内从开场玩到章末（芦湾河滩与旧渡暂借山路布景，令狐冲、黄蓉、萧峰等为占位形象，动作为补间占位，对白为第一章试听配音、未锁稿），“继续旅程”读最近存档，M0 展示页改由“场景目录”进入；同日按用户试玩反馈自查打磨：修正立绘错配、Esc 误回标题、战斗用药不扣除、样例设置页等问题，接入 BGM、环境声与音效、真正的设置页、鼠标点地行走、章终回顾，河滩与旧渡借景改装，补齐第一章说话人物的全身形象与对话立绘（经典人物外形为待核视觉草案）；随后按用户试听试看反馈，把程序合成音效整体换成 Freesound CC0 实录剪辑（未经人耳审听），并修正四张男角色立绘的白眼珠；同日补上人物成长：主角 1–8 级按经验升级并分配潜能，5 槽装备、招式与心法装配、修为与武学熟练度，芦湾街杂货摊买卖，探索中 C 人物页、I 行囊页（剧情战的主角改由这些数据现推，规则测试增至 107 项）；同日补上存档删除与存档缩略图，标题页与游戏菜单共用带缩略图的存档卡；并完成第一章令狐冲、黄蓉、萧峰的剧情锚点审核（已查原文、出版版本待对校，锚点写入内容数据并由校验器检查）；同日江湖大地图接入游戏：探索中按 M 打开、码头乘船点选中目的地，芦湾与芦湾旧渡可乘渡船或步行往返，章末出现江南粮仓、山门路两处下一章预告地标（舆图仍为程序化占位）；同日补上队伍阵位与伙伴：探索中按 P 打开队伍页，可调换前后排站位（剧情战按此站位），陆青禾作为伙伴随主角成长、离队期间有限追赶，令狐冲等经典人物为暂时同行（规则测试 127 项）；2026-10-03 起令狐冲、黄蓉、萧峰在剧情战里使用各自的个人武学（独孤九剑、打狗棒法、降龙十八掌，分式名的原著依据待对校），同行者先手（识破伪装、松动闸绳、提前救人）与支线结果改变战斗开局（规则测试 134 项）；同日进入 M3 中不依赖试玩的系统项，先补城镇洗点：在芦湾街与江南客栈可花银两收回已分配潜能，或把修炼过的招式退回第 1 阶并返还修为（规则测试 138 项）；2026-10-04 补上第一章关键战斗语音：32 句战斗喊声第一稿（开战、三侠招式、首领蓄力预兆与阶段、重伤、倒下、胜利；未锁稿，试听配音已生成、未经人耳审核），按优先级与冷却挑句、倍速只说关键句，另加对话“自动推进”设置（规则测试 145 项）；同日开发用跳关与战斗测试台、主角对话立绘与立绘统一比例、芦湾街草地精修，以及 M3-01 芦湾河滩与芦湾旧渡专属布景（江面、雨后泥滩、AI 芦苇、旧渡栈桥、河堤水门，取代借用的山路溪涧；待用户审看），以及芦湾街、江南客栈的光影整理（四张图的光色随游戏时辰分白天 / 黄昏 / 夜，城镇投影与夜间窗光灯火，客栈夜景；待用户审看），以及 M3-02 人物动作（主角样板之后按用户反馈补全：转身修正、Shift 快走换跑步帧、长裙随步摆动，陆青禾、三侠、唐守亭、押运打手的跑步 / 背面 / 战斗关键姿势共 64 帧；待用户审看）（规则测试 150 项）；用户决定 M3 做完再整体试玩；尚未经键鼠实机试玩，不能称为已交付的玩法 Demo。进度与验证记录见[开发计划](./docs/DEVELOPMENT_PLAN.md)的 M0–M3 进度记录。目标平台仅 Windows x64。

## 工程结构

| 路径 | 内容 |
|---|---|
| `game/` | Godot 4.7.2 .NET 工程；入口 `scenes/boot/Boot.tscn` → 标题页（新的旅程 / 继续旅程进入 `scenes/world/Exploration.tscn`，场景目录进入 M0 展示页） |
| `src/` | `Domain` / `Application` / `Infrastructure` 规则类库（M1：战斗内核、战斗会话、内容加载与校验；M2：世界规则、游戏会话、存档） |
| `content/` | 手工维护的 JSON 内容源（含逐章对白 `content/dialogue/`）；`dotnet run --project tools/ContentCompiler` 校验并生成 `game/generated/content` |
| `tools/` | 构建导出脚本与内容、战斗、配音工具 |
| `tests/` | 测试项目（xUnit，M1 锁定版本）：`dotnet test tests/Domain/WuxiaWorld.Domain.Tests` |
| `art_source/`、`voice_source/` | 美术与配音源文件（Git LFS） |

开发环境：.NET SDK 10.0.401（`global.json` 锁定补丁级前滚）、Godot 4.7.2 .NET（`4.7.2.stable.mono`）编辑器及同版导出模板、Git LFS；该组合已于 2026-09-23 在 Windows 11 上完成构建与导出启动验证。两台开发机均可用 winget 安装：`winget install --id Microsoft.DotNet.SDK.10 --version 10.0.401 -e`、`winget install --id GodotEngine.GodotEngine.Mono --version 4.7.2 -e`；导出模板从 Godot 官方发布页下载 `Godot_v4.7.2-stable_mono_export_templates.tpz`，解压 `templates/` 到 `%APPDATA%\Godot\export_templates\4.7.2.stable.mono`；并把编辑器路径设为用户环境变量 `GODOT_BIN`。用编辑器打开 `game/project.godot` 运行；导出见 [tools/README.md](./tools/README.md)。

当前方案：Godot .NET + C#，暂定斜俯视高清探索、独立侧视回合战斗。

三篇故事均为待制作的原创游戏剧情设计，尚非已实现内容。第一篇结尾是阶段性处置，完整游戏在第三篇大战和华山论剑后收束；主角其中一个结局可独自返回现代。具名成年女性角色设有可选择的恋爱路径，可在彼此知情同意下拥有多位恋人。登场人物的原著剧情阶段、年龄与身份依据需在制作前逐项核验；公开发行所需内容授权也尚未确认。

角色采用 AI 配音，由人工试听修整，开发期生成并随游戏包离线播放。角色音色固定，供应商通过小样比较后选定。

1. 第一阶段：交付可切换场景与主要 UI 的 Windows 视觉 Demo，使用样例数据核对画风、人物比例和视角；可附少量配音试听，不阻塞视觉交付。
2. 用户认可画风与视角后，第二阶段交付约 60 分钟“相遇—成长—战斗—选择”玩法 Demo，主线对白全配音并加入关键战斗语音。
3. 再依据试玩反馈制作三篇连续故事，同一存档跨篇推进，最终交付大战、华山论剑和完整结局。
